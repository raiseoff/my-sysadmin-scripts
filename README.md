# my-sysadmin-scripts

Автоматический подъём веб-сервиса с нуля: Docker-образ, RAID/LVM на
loop-устройствах, Nginx с TLS, systemd-служба. Одной командой на чистой машине.

## Что делает `bootstrap.sh`

Скрипт рассчитан на запуск на **свежей** машине (например, Killercoda Ubuntu)
и выполняет пять шагов без единого вопроса к оператору:

1. **Образ и контейнер** — собирает `my-script` из `Dockerfile`, создаёт
   контейнер `my-app` с пробросом порта `8080` и томом `/var/log:/var/log:ro`.
2. **RAID/LVM** — создаёт три файла-образа `disk{1,2,3}.img` в `/mnt/raid-lab`,
   подключает их через `losetup`, собирает RAID 1 (`/dev/md0`) из двух,
   поверх третьего строит LVM-группу `vg_data` с томом `lv_logs`.
   Монтирует в `/mnt/raid` и `/mnt/logs`.
3. **Nginx и TLS** — ставит nginx и openssl, генерирует самоподписанный
   сертификат, настраивает редирект `80 → 443` и reverse-proxy на
   `127.0.0.1:8080`.
4. **systemd** — создаёт юнит `my-app.service`, включает автозапуск и
   запускает службу.
5. **Самопроверка** — активно ждёт готовности сервиса (до 30 секунд),
   затем печатает `curl -I`, состояние RAID, монтирования и systemd-службы.

## Быстрый старт

```bash
git clone https://github.com/<логин>/my-sysadmin-scripts.git
cd my-sysadmin-scripts
./bootstrap.sh
```

## Требования

- **ОС:** Ubuntu 22.04 (проверено на Killercoda)
- **Docker:** устанавливается по умолчанию
- **Права:** `root` или `sudo`
